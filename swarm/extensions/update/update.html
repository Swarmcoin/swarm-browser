How this works

  • Once a day this browser reads one public file, https://swarm.green/browser/updates.json: the list of SWARM Browser versions.
  • The list is signed. This browser checks the signature against a key built into it before it believes any of it, and ignores a list that is unsigned, altered, older than one it has already seen, or that offers an older version than the one you have.
  • Nothing about you is sent: no cookies, no identifier, no page you visited. swarm.green sees that a SWARM Browser asked, and from which internet address, as any website would.
  • It never downloads or installs anything. The download is a link you click, like any other.
